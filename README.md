# Sustancia 'X' Web

Minimal static discography site for **Sustancia 'X'**.

![Demo](assets/readme-demo.gif)

## Run locally

Open `index.html` directly, or serve the folder with any static server.

## Deploy

This repo is ready to ship as a static site on Vercel.

Parallax downloads live at `/parallax/`, with a private license desk at
`/parallax/admin/`. See [Parallax setup and publishing](docs/PARALLAX.md) for local
preview, owner access, server environment variables and release updates. The
original discography pages remain unchanged. Use `python3 scripts/serve_parallax.py`
for local preview when owner secrets exist; it blocks private files.
